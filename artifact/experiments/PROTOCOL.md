# Coarsened-time relay counts

Design fixed before inspecting benchmark outcomes, 2026-11-23. The experimental unit is a whole occupied time bucket, aligned by integer division of the published timestamp. The event table contains directed, individually distinguishable, non-self events. Duplicates remain. Bitcoin records represent ratings, and the query ignores the rating value. Use all four SNAP traces (CollegeMsg, email-Eu-core-temporal, Bitcoin OTC and Alpha), each at 60, 3,600 and 86,400 seconds. Email timestamps are relative to the source origin. The primary comparison uses 3,600 seconds. Other resolutions test sensitivity. Analyze only paths whose two events occupy the same bucket. All three vertices must be distinct. No adjacency-in-time requirement or inferred information flow.

The primary output is the conditional variance of a weighted sum of per-relay path counts under independent uniform total orders in the observed buckets. Use all relays with weight 1 for the primary query, odd-ID relays for a subgroup, and odd minus even for a signed contrast. ID parity is a reproducible algebraic test workload with no behavioral interpretation.

1. Check exact first and second moments against direct enumeration of every event permutation on small random/adversarial bins, including repeated endpoints, reciprocal events and cycles. Require exact equality for all tested weights. Also compare moment numerators against explicit compatible-pair enumeration on all real hourly bins. One discrepancy suspends the claim.
2. Compare the full variance with (i) independent event-pair indicators, (ii) exact relay marginal variances summed as if relays were independent and (iii) direct shuffle-and-count. The first two comparators omit different dependencies. Report all data, query and resolution cells. Count a material discrepancy when variance differs by at least 20% relative to exact for the primary hourly query. Require this on at least two datasets for an empirical recommendation. No sample-level significance claim is attached to this threshold.
3. Measure endpoint aggregation and explicit compatible-pair enumeration using identical parsed input and language on one server CPU worker, alternating order with repeated timings. Show sparse regimes where enumeration wins. Separate IO/sorting from kernel timings. High-activity synthetic bins test scaling; report their construction separately.
4. Replay the published finer timestamp order, averaging over ties still present at the native precision. Compare its count with the coarse permutation mean in units of coarse-null standard deviation. This comparison describes a discrepancy with a reference randomization. It cannot establish a posterior for true unseen order. Record source checksums, runner, raw results and command.
5. Decision: recommend the conditional-moment direction if correctness checks and the predefined discrepancy criterion pass and a targeted prior-art review supports a distinct graph-query contribution. Runtime gains are supplementary. Withhold the empirical or novelty claim where evidence falls short.
